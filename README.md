# Wolvox Transfer

Delete Yazılım ve İnovasyon — Wolvox Transfer İrsaliyesi otomatik güncelleme dosyaları.

Kurulu programlar `guncelleme/surum.txt` dosyasına bakar; daha yeni sürüm varsa `guncelleme/TransferIrsaliye.exe` dosyasını indirip kendini günceller.

Yeni sürüm yayınlamak için bu iki dosyayı yenisiyle değiştirmek yeterlidir.
